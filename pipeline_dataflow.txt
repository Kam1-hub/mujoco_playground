  # G1 训练 Pipeline 数据流图

  ## 概览

  本文档以数据流的形式描述 G1 人形机器人训练的完整
  pipeline，从环境初始化到策略训练的全过程。


  ## 1. 训练入口数据流

  ### 1.1 JAX PPO 训练流程 (train_jax_ppo.py)

  用户命令
    │
    ├─> train-g1-jax --env_name G1JoystickFlatTerrain --num_timesteps 200000000
    │
    v
  命令行参数解析 (absl.flags)
    │
    ├─> _ENV_NAME: "G1JoystickFlatTerrain"
    ├─> _NUM_TIMESTEPS: 200000000
    ├─> _NUM_ENVS: 8192
    ├─> _IMPL: "jax"
    ├─> _DOMAIN_RANDOMIZATION: False
    └─> _USE_WANDB: False
    │
    v
  获取 RL 配置
    │
    ├─> get_rl_config(env_name)
    │     │
    │     └─> locomotion_params.brax_ppo_config()
    │           │
    │           └─> 返回 ConfigDict:
    │                 - num_timesteps: 200M
    │                 - num_evals: 20
    │                 - num_envs: 8192
    │                 - learning_rate: 3e-4
    │                 - entropy_cost: 0.005
    │                 - network: Policy(512,256,128), Value(512,256,128)
    │
    v
  加载环境
    │
    ├─> registry.load(env_name, config, config_overrides)
    │     │
    │     └─> locomotion.load()
    │           │
    │           └─> g1_joystick.Joystick(task="flat_terrain")
    │                 │
    │                 └─> G1Env.init()
    │                       │
    │                       ├─> 加载 XML: scene_mjx_feetonly_flat_terrain.xml
    │                       ├─> 创建 MuJoCo 模型: mujoco.MjModel
    │                       ├─> 创建 MJX 模型: mjx.put_model(m)
    │                       └─> 返回 Joystick 环境实例
    │
    v
  环境包装
    │
    ├─> wrapper.wrap_for_brax_training(env, episode_length, action_repeat)
    │     │
    │     └─> 返回 Brax 兼容的环境
    │
    v
  初始化训练器
    │
    ├─> ppo.train(
    │       environment=env,
    │       network_factory=make_ppo_networks,
    │       num_timesteps=200M,
    │       num_envs=8192,
    │       ...
    │     )
    │
    v
  训练循环 (由 Brax PPO 管理)
    │
    └─> 返回: (make_inference_fn, params, metrics)

  ## 2. 环境初始化数据流

  registry.load("G1JoystickFlatTerrain")
    │
    v

    │
    ├─> 检查环境名称是否在 _envs 字典中

    │     └─> 如果不存在，克隆 mujoco_menagerie 仓库
    │
    └─> 调用 _envs[env_name](config, config_overrides)
          │
          └─> functools.partial(g1_joystick.Joystick, task="flat_terrain")
                │
                v
              Joystick.init(config, config_overrides, task)
                │
                ├─> 合并配置: config + config_overrides
                ├─> 获取 XML 路径: g1_constants.task_to_xml(task)
                │     │
                │     └─> 返回: scene_mjx_feetonly_flat_terrain.xml
                │
                └─> 调用父类 G1Env.init(xml_path, config)
                      │
                      v
                    G1Env.init(xml_path, config)
                      │
                      ├─> 加载资源: get_assets()
                      │     │
                      │     ├─> 读取 XML 文件
                      │     ├─> 读取纹理: hfield.png, rocky_texture.png
                      │     └─> 返回 assets 字典
                      │
                      ├─> 创建 MuJoCo 模型
                      │     │
                      │     └─> mujoco.MjModel.from_xml_string(xml, assets)
                      │
                      ├─> 创建 MJX 模型
                      │     │
                      │     └─> mjx.put_model(mujoco_model)
                      │

                      │     ├─> 接触力传感器 ID
                      │     └─> 线速度传感器 ID
                      │
                      └─> 调用父类 MjxEnv.init(mujoco_model, mjx_model, config)
                            │
                            └─> 初始化环境基类
                                  │
                                  ├─> self.dt = config.ctrl_dt
                                  ├─> self.episode_length =
  config.episode_length
                                  └─> 返回环境实例


  ## 3. Episode 执行数据流

  ### 3.1 Reset 流程

  env.reset(rng)
    │
    v
  Joystick.reset(rng)
    │
    ├─> 分割随机数生成器
    │     │
    │     └─> rng_pos, rng_vel, rng_cmd = jax.random.split(rng, 3)
    │
    ├─> 初始化关节位置
    │     │
    │     ├─> 从 keyframe "knees_bent" 获取默认姿态
    │     ├─> 添加随机扰动: qpos += random.uniform(-0.1, 0.1)
    │     └─> qpos: (nq,) 数组
    │
    ├─> 初始化关节速度
    │     │
    │     ├─> qvel = random.uniform(-0.1, 0.1)
    │     └─> qvel: (nv,) 数组
    │
    ├─> 采样命令
    │     │
    │     ├─> lin_vel_x: uniform(0.0, 1.5) m/s
    │     ├─> lin_vel_y: uniform(-0.5, 0.5) m/s
    │     ├─> ang_vel_yaw: uniform(-1.0, 1.0) rad/s
    │     └─> command: (3,) 数组
    │
    ├─> 创建初始 MJX data
    │     │
    │     └─> data = mjx_model.make_data()
    │           data.qpos = qpos
    │           data.qvel = qvel
    │
    ├─> 前向仿真
    │     │
    │     └─> data = mjx.forward(mjx_model, data)
    │
    ├─> 生成初始观测
    │     │
    │     └─> obs = self._get_obs(data, command, phase, last_action)
    │
    └─> 返回 State
          │
          └─> State(
                data=data,           # MJX data
                obs=obs,             # 观测字典
                reward=0.0,          # 初始奖励
                done=0.0,            # 未结束
                metrics={},          # 空指标
                info={"command": command, "phase": phase, ...}
              )

  ### 3.2 Step 流程

  env.step(state, action)
    │
    v
  Joystick.step(state, action)
    │
    ├─> 提取当前状态
    │     │
    │     ├─> data = state.data
    │     ├─> command = state.info["command"]
    │     ├─> phase = state.info["phase"]
    │     └─> last_action = state.info.get("last_action", action)
    │
    ├─> 应用动作
    │     │
    │     ├─> 缩放动作: action_scaled = action * action_scale
    │     ├─> 添加到默认姿态: ctrl = default_qpos + action_scaled
    │     └─> data.ctrl = ctrl
    │
    ├─> 应用推力扰动 (可选)
    │     │
    │     └─> data.xfrc_applied[pelvis_id] = random_force
    │
    ├─> 物理仿真 (10 步，sim_dt=0.002s)
    │     │
    │     └─> for _ in range(10):
    │           data = mjx.step(mjx_model, data)
    │
    ├─> 更新相位
    │     │
    │     └─> phase = (phase + dt * phase_freq) % 1.0
    │
    ├─> 生成观测
    │     │
    │     └─> obs = self._get_obs(data, command, phase, action)
    │           │
    │           v
    │         _get_obs(data, command, phase, last_action)
    │           │
    │           ├─> 提取传感器数据
    │           │     │
    │           │     ├─> gyro = data.sensordata[gyro_id]              # (3,)
    │           │     ├─> gravity = data.sensordata[gravity_id]        # (3,)
    │           │     ├─> accelerometer = data.sensordata[accel_id]    # (3,)
    │           │     ├─> qpos = data.qpos[7:]                         # (29,)
  关节角
    │           │     ├─> qvel = data.qvel[6:]                         # (29,)
  关节速度
    │           │     └─> contact = floor_found(data)                  # (2,)
  脚部接触
    │           │
    │           ├─> 构建 state 观测 (101 维)
    │           │     │
    │           │     └─> state = concat([
    │           │           gyro,              # 3
    │           │           gravity,           # 3
    │           │           command,           # 3
    │           │           qpos,              # 29
    │           │           qvel,              # 29
    │           │           last_action,       # 29
    │           │           sin(2πphase),     # 2
    │           │           cos(2πphase),     # 2
    │           │           phase              # 1
    │           │         ])                   # 总计: 101
    │           │
    │           └─> 构建 privileged_state 观测 (150+ 维)
    │                 │
    │                 └─> privileged_state = concat([
    │                       state,                    # 101
    │                       raw_gyro,                 # 3
    │                       accelerometer,            # 3
    │                       raw_gravity,              # 3
    │                       linvel,                   # 3
    │                       angvel,                   # 3
    │                       qpos_full,                # 29
    │                       qvel_full,                # 29
    │                       root_height,              # 1
    │                       actuator_forces,          # 29
    │                       contact,                  # 2
    │                       feet_velocity,            # 6
    │                       air_time                  # 2
    │                     ])                          # 总计: 150+
    │
    ├─> 计算奖励
    │     │
    │     └─> reward, reward_dict = self._get_reward(data, command, phase,
  action)
    │           │
    │           v
    │         _get_reward(data, command, phase, action)
    │           │
    │           ├─> 提取状态信息
    │           │     │
    │           │     ├─> linvel = data.qvel[:3]                    # 线速度
    │           │     ├─> angvel = data.qvel[3:6]                   # 角速度
    │           │     ├─> qpos = data.qpos[7:]                      # 关节角
    │           │     ├─> qvel = data.qvel[6:]                      # 关节速度
    │           │     ├─> z_up = data.xmat[pelvis_id, 6:9]          # 躯干朝向
    │           │     ├─> height = data.xpos[pelvis_id, 2]          # 躯干高度
    │           │     └─> feet_contact = floor_found(data)          # 脚部接触
    │           │
    │           ├─> 计算跟踪奖励
    │           │     │
    │           │     ├─> r_lin_vel_x = exp(-|linvel[0] - cmd[0]|²)    #
  前向速度跟踪
    │           │     ├─> r_lin_vel_y = exp(-|linvel[1] - cmd[1]|²)    #
  侧向速度跟踪
    │           │     └─> r_ang_vel = exp(-|angvel[2] - cmd[2]|²)      #
  角速度跟踪
    │           │
    │           ├─> 计算基础奖励
    │           │     │
    │           │     ├─> r_height = exp(-|height - target_height|²)   #
  高度保持
    │           │     ├─> r_upright = z_up[2]                          #
  躯干直立
    │           │     ├─> r_energy = -sum(|torque * qvel|)             #
  能量消耗
    │           │     └─> r_action_rate = -sum(|action - last_action|²) #
  动作平滑
    │           │
    │           ├─> 计算脚部奖励
    │           │     │
    │           │     ├─> r_slip = -sum(|feet_linvel_xy|) * contact    #
  脚部滑动
    │           │     ├─> r_clearance = feet_height * (1 - contact)    #
  摆动腿间隙
    │           │     ├─> r_air_time = air_time * (1 - contact)        #
  空中时间
    │           │     └─> r_phase = -|contact - target_contact(phase)| #
  相位跟踪
    │           │
    │           ├─> 计算姿态奖励
    │           │     │
    │           │     ├─> r_hip_dev = -|qpos[hip_joints] - default|²  #
  髋关节偏差
    │           │     ├─> r_knee_dev = -|qpos[knee_joints] - default|² #
  膝关节偏差
    │           │     └─> r_joint_limit = -sum(beyond_limit(qpos))     #
  关节限位
    │           │
    │           ├─> 加权求和
    │           │     │
    │           │     └─> total_reward = sum(scale_i * reward_i)
    │           │           │
    │           │           ├─> lin_vel: 1.0
    │           │           ├─> ang_vel: 0.75
    │           │           ├─> air_time: 2.0
    │           │           ├─> phase: 1.0
    │           │           ├─> slip: -0.25
    │           │           ├─> hip_deviation: -0.25
    │           │           └─> ...
    │           │
    │           └─> 返回: (total_reward, reward_dict)
    │
    ├─> 检查终止条件
    │     │
    │     └─> done = self._get_termination(data)
    │           │
    │           ├─> 检查躯干高度: height < 0.3
    │           ├─> 检查躯干倾斜: z_up[2] < 0.5
    │           ├─> 检查碰撞: non_feet_contact > 0
    │           └─> 返回: done (0 或 1)
    │
    ├─> 更新指标
    │     │
    │     └─> metrics = {
    │           "reward/total": reward,
    │           "reward/lin_vel": reward_dict["lin_vel"],
    │           "reward/ang_vel": reward_dict["ang_vel"],
    │           ...
    │           "state/height": height,
    │           "state/velocity": linvel_norm,
    │           ...
    │         }
    │
    └─> 返回新状态
          │
          └─> State(
                data=new_data,
                obs=obs,
                reward=reward,
                done=done,
                metrics=metrics,
                info={"command": command, "phase": phase, "last_action":
  action}
              )


  ## 4. 训练循环数据流 (Brax PPO)

  ppo.train(environment, network_factory, ...)
    │
    v
  初始化
    │
    ├─> 创建策略网络
    │     │
    │     └─> policy_network = network_factory(
    │           obs_size=101,
    │           action_size=29,
    │           hidden_layers=(512, 256, 128)
    │         )
    │
    ├─> 创建价值网络
    │     │
    │     └─> value_network = network_factory(
    │           obs_size=150+,  # privileged_state
    │           output_size=1,
    │           hidden_layers=(512, 256, 128)
    │         )
    │
    └─> 初始化参数
          │
          └─> params = init_params(rng, policy_network, value_network)
    │
    v
  训练循环 (200M 步 / 8192 环境)
    │
    └─> for iteration in range(num_iterations):
          │
          ├─> 收集经验 (Rollout)
          │     │
          │     └─> for step in range(unroll_length):  # 20 步
          │           │
          │           ├─> 策略推理
          │           │     │
          │           │     └─> action, log_prob = policy(params, obs["state"])
          │           │           │
          │           │           ├─> obs["state"]: (8192, 101)
          │           │           ├─> hidden: (8192, 512) → (8192, 256) →
  (8192, 128)
          │           │           ├─> mean: (8192, 29)
          │           │           ├─> std: (8192, 29)
          │           │           ├─> action = sample(Normal(mean, std))
          │           │           └─> log_prob = log_prob(action)
          │           │
          │           ├─> 环境交互
          │           │     │
          │           │     └─> state = env.step(state, action)
          │           │           │
          │           │           └─> (见 Section 3.2)
          │           │
          │           ├─> 价值估计
          │           │     │
          │           │     └─> value = value_network(params,
  obs["privileged_state"])
          │           │           │
          │           │           ├─> obs["privileged_state"]: (8192, 150+)
          │           │           ├─> hidden: (8192, 512) → (8192, 256) →
  (8192, 128)
          │           │           └─> value: (8192, 1)
          │           │
          │           └─> 存储 transition
          │                 │
          │                 └─> buffer.add(obs, action, reward, value,
  log_prob, done)
          │
          ├─> 计算优势函数 (GAE)
          │     │
          │     └─> for t in reversed(range(unroll_length)):
          │           │
          │           ├─> delta = reward[t] + gamma * value[t+1] - value[t]
          │           ├─> advantage[t] = delta + gamma * lambda *
  advantage[t+1]
          │           └─> returns[t] = advantage[t] + value[t]
          │
          ├─> 策略更新 (4 epochs × 32 minibatches)
          │     │
          │     └─> for epoch in range(num_updates_per_batch):
          │           │
          │           └─> for minibatch in range(num_minibatches):
          │                 │
          │                 ├─> 采样 minibatch
          │                 │     │
          │                 │     └─> batch = sample(buffer, batch_size=256)
          │                 │
          │                 ├─> 计算策略损失
          │                 │     │
          │                 │     ├─> new_log_prob =
  policy.log_prob(batch.action)
          │                 │     ├─> ratio = exp(new_log_prob -
  batch.old_log_prob)
          │                 │     ├─> clipped_ratio = clip(ratio, 1-ε, 1+ε)  #
  ε=0.2
          │                 │     ├─> policy_loss = -min(
          │                 │     │     ratio * advantage,
          │                 │     │     clipped_ratio * advantage
          │                 │     │   ).mean()
          │                 │     └─> entropy_loss = -entropy(policy).mean()
          │                 │
          │                 ├─> 计算价值损失
          │                 │     │
          │                 │     ├─> new_value = value_network(batch.obs)
          │                 │     ├─> clipped_value = batch.old_value + clip(
          │                 │     │     new_value - batch.old_value, -ε, ε
          │                 │     │   )
          │                 │     └─> value_loss = max(
          │                 │           (new_value - batch.returns)²,
          │                 │           (clipped_value - batch.returns)²
          │                 │         ).mean()
          │                 │
          │                 ├─> 总损失
          │                 │     │
          │                 │     └─> loss = policy_loss
          │                 │              + value_coef * value_loss
          │                 │              + entropy_coef * entropy_loss
          │                 │
          │                 └─> 梯度更新
          │                       │
          │                       ├─> grads = jax.grad(loss)(params)
          │                       ├─> grads = clip_by_global_norm(grads,
  max_norm=1.0)
          │                       └─> params = adam_update(params, grads,
  lr=3e-4)
          │
          ├─> 评估 (每 10M 步)

  8. 数据维度总结

  8.1 输入维度

  观测空间:
    - state (策略输入): (101,)
      ├─> 传感器: 3 + 3 = 6
      ├─> 命令: 3
      ├─> 关节: 29 + 29 = 58
      ├─> 动作: 29
      └─> 相位: 2 + 2 + 1 = 5

    - privileged_state (价值输入): (150+,)
      └─> state + 额外传感器 + 状态信息

  动作空间:
    - action: (29,)
      └─> 关节位置命令（相对于默认姿态）

  8.2 中间维度

  策略网络:
    input: (batch, 101)
      ↓ Linear + ReLU
    hidden1: (batch, 512)
      ↓ Linear + ReLU
    hidden2: (batch, 256)
      ↓ Linear + ReLU
    hidden3: (batch, 128)
      ↓ Linear (mean)
    mean: (batch, 29)
      ↓ Linear (std)
    std: (batch, 29)
      ↓ Sample
    action: (batch, 29)

  价值网络:
    input: (batch, 150+)
      ↓ Linear + ReLU
    hidden1: (batch, 512)
      ↓ Linear + ReLU
    hidden2: (batch, 256)
      ↓ Linear + ReLU
    hidden3: (batch, 128)
      ↓ Linear
    value: (batch, 1)

  8.3 批处理维度

  训练时:
    - 并行环境: 8192
    - Rollout 长度: 20
    - 总样本: 8192 × 20 = 163,840
    - Minibatch 大小: 256
    - Minibatch 数量: 32
    - 每批更新: 4 epochs

  数据流:
    obs: (8192, 101) → policy → action: (8192, 29)
    obs: (8192, 150+) → value → value: (8192, 1)

    buffer: (163840, ...)
      ↓ shuffle + split
    minibatch: (256, ...)
      ↓ 32 batches × 4 epochs
    updates: 128 次梯度更新

  9.1 JIT 编译

  首次调用

    │

    │     │
    │     └─> JAX 追踪计算图
    │           │
    │           └─> 编译为 XLA
    │

          │
          └─> JAX 追踪计算图
                │
                └─> 编译为 XLA

  后续调用
    │
    └─> 直接执行编译后的 XLA 代码
          │
          └─> 速度提升 10-100x

  9.2 向量化

  单环境 (慢):
    for i in range(8192):
      state[i] = env.step(state[i], action[i])

  向量化 (快):
    states = vmap(env.step)(states, actions)
      │
      └─> 并行执行 8192 个环境
            │
            ├─> GPU: 真正的并行
            └─> CPU: SIMD 向量化

  9.3 内存布局

  数据对齐:
    obs: (8192, 101) → 连续内存
      │
      └─> GPU 合并访问
            │
            └─> 高带宽利用率

  避免复制:
    JAX 数组 → 零拷贝 → GPU
      │
      └─> 减少 CPU-GPU 传输
